🎯 How to Use FileSetu File Manager

FileSetu is a privacy-first browser tool that lets you inspect, hash, preview, and organize files without uploading anything to a server. Every operation happens entirely on your device, making it safe for sensitive documents, images, code, and more.

  1. Add files: Click the dropzone, drag & drop files onto it, or paste copied files with Ctrl+V. You can select multiple files at once.
  2. Wait for inspection: FileSetu automatically starts computing a SHA-256 checksum for each file. You'll see a progress bar while hashing is in progress.
  3. Preview any file: Click the 👁 button on a file card to open a preview. Images, videos, audio, and text/code files can be viewed directly inside the modal.
  4. Download or remove: Use the ⬇ button to download the original file back to your device. The ✕ button removes it from the list (the file itself is never deleted from your computer).
  5. Search & filter: Use the search box to find files by name. The category tabs (Docs, Images, Media, Archives, Code) help you narrow down the list quickly.

🔐 Key Features

  • Real SHA-256 checksum generation for integrity verification
  • Client-side preview for images, audio, video, and text/code files
  • Sorting by category, search filtering, and duplicate detection
  • No data ever leaves your browser — 100% offline capable
  • Works on mobile, tablet, and desktop devices
  • Light and dark mode support for comfortable viewing

❓ Frequently Asked Questions

Does FileSetu upload my files to a server?

No. All processing happens locally in your browser using the Web Crypto API. Your files never leave your device.

What is the SHA-256 checksum used for?

It creates a unique digital fingerprint of a file. You can compare it with a known hash to verify the file hasn't been corrupted or tampered with.

Can I preview PDF or Excel files?

Currently, PDF and binary office formats cannot be rendered inside the tool. You can still download them or view their metadata and hash.

Is there a file size limit?

There is no hard limit, but very large files may take longer to hash and preview. For best performance, keep files under ~50 MB.

Does this work on mobile devices?

Yes, FileSetu is fully responsive and works on smartphones, tablets, and desktops. Touch gestures and drag-and-drop are supported.
