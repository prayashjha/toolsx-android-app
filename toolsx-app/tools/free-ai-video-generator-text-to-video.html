🛠️ How This Text to Video Tool Works

Tools-X Text to Video Converter is an advanced browser-based multimedia tool that transforms your written shayari, quotes, or any text into cinematic 9:16 vertical videos — complete with AI voiceover, auto-generated ambient music, and copyright-free Pexels video backgrounds. The entire process runs 100% offline in your browser — no API key, no server upload, no signup. Perfect for Instagram Reels, YouTube Shorts, WhatsApp Status, and TikTok content creators.

1

Text + Mood Input

User writes shayari and selects mood. System detects lines and calculates timing based on total duration.

2

Free Video Library

Copyright-free videos load directly from Pexels CDN — no API key. Sequential loader tries multiple URLs. Fallback animated gradient mode ensures the tool never fails!

3

AI Voice (Text-to-Speech)

Two free engines: StreamElements TTS (for MP3 download) and Browser Web Speech API (for live preview). Hindi/English voices available — Aditi, Hemant, Amy, Brian.

4

Auto Music + Recording

Web Audio API oscillators generate pleasant ambient chords (100% original, zero copyright). MediaRecorder mixes canvas + voice + music into final video.

📋 Step-by-Step Working Process

1
User Input
Shayari is pasted. Lines count and duration are calculated automatically.
2
Video Fetch
Copyright-free video loads from Pexels CDN based on selected mood with 6-second timeout per URL.
3
Fallback Mode
If video fails, canvas uses animated gradient background — video still gets created!
4
Text Animation
Canvas renders text every frame with line-by-line, typewriter, fade, slide animations.
5
AI Voice Generation
StreamElements free TTS creates MP3. Web Audio API decodes and mixes it into recording.
6
Music Synthesis
Web Audio oscillators generate pleasant ambient chords — 100% original.
7
Final Recording
MediaRecorder records canvas + audio at 30fps. VP9/VP8 codec fallback system.
8
Download & Share
One-click download. Upload to Instagram Reels, YouTube Shorts, WhatsApp Status.
